Security model
  • ✓ A new AES-256 Fernet key is generated per upload session — keys never leave the server.
  • ✓ Blocks are stored with a unique UUID prefix so different files never overwrite each other.
  • ✓ BLOB_READ_WRITE_TOKEN is an environment variable — never embedded in frontend JS.
  • ✓ SHA-256 hash comparison catches any corruption or tampering during transit.
