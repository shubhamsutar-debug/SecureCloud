Security guarantees
🔑A new Fernet key is generated per upload — it lives only in server RAM and is never sent to the browser.
🆔Each run gets a UUID4 path prefix — blocks from different files never collide in the Blob store.
🔒BLOB_READ_WRITE_TOKEN is an environment variable — never embedded in any frontend code.
✅SHA-256 hashes are compared after reconstruction — any corruption or tampering causes an explicit FAIL.
